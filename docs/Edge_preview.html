Edge Detection

CFS Crafter uses MATLAB's Image Processing Toolbox to perform edge detection on selected CFS-Crafter masks, CFS-Crafter images, & image files. Here we provide the basic procedure of how to use the edge detection in CFS Crafter. For details on the edge detection algorithm, please refer to MATLAB's Help Center.

1. Edge Density

Edge Density is the percentage of pixels that are identified as edges with respect to the total number of pixels in the image.

When creating CFS-Crafter masks or a CFS-Crafter image, CFS Crafter will perform a default edge detection with canny method and default threshold chosen by MATLAB. The average edge density over all frames, edge detection method and threshold will be stored in stimuli_property.

2. Edge Detection Method & Threshold

Suppose the user is particularly interested in exploring different edge detection methods & thresholds, and is interested in the binary edge images. In that case, the user can alter the edge detection method & threshold in Analysis, and select Preview Edges to preview and save the edges for all selected stimuli and updated edge density.

There are 4 methods to choose from in CFS Crafter:

  • canny & approxcanny

    • canny & approxcanny use 2 thresholds; edges are found by looking for the local maxima of the gradient. The edges with strength smaller than the lower threshold will be ignored, and those with strength higher than the higher limit will be preserved. Those with an edge strength between the lower & higher limits will only be preserved if they are connected to the strong edges.

    When specifying the threshold, the user can input either 1 scalar as the higher threshold value. In that case, the lower limit will be set as 0.4 * upper threshold. Otherwise, the user can specify both thresholds with a comma separating the two (i.e. low,high).

  • Sobel

    • Find maximum derivative using Sobel approximation. Edges smaller than the threshold value will be ignored.

  • log

    • Finds edges by looking for zero-crossings after filtering I with a Laplacian of Gaussian (LoG) filter. If the user specifies the threshold value as 0, then the output image has closed contours because it includes all the zero-crossings in the input image

3. Edge Preview

If the Preview Edges check box is selected in Analysis, an Edge Preview interface will be opened after analysis. In this interface, the user is presented with the preview (first frame) of the binary edge image of each stimulus, the edge detection method & threshold used, and average edge density of each stimulus. The user can also save the edges as a .mat file, which contains the above-mentioned edge information and the full binary edge array for each stimulus.
